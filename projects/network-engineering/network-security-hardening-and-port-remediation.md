# Network Security Hardening & Port Remediation

## Overview

Led network hardening activities focused on identifying unnecessary service exposure and reducing security risks across network infrastructure.

The activity involved verifying open management ports, assessing compliance with security requirements, and implementing corrective actions to eliminate insecure access methods.

---

## Objective

Improve network security posture by identifying and remediating unnecessary or insecure service exposures.

Key objectives included:

- Reduce attack surface
- Identify insecure protocols
- Improve compliance
- Strengthen infrastructure security
- Support security best practices

## Port Verification Activities

Performed regular verification of exposed services across network devices and infrastructure components.

Activities included:

## Telnet Remediation Activities

Validated whether Telnet services were enabled on infrastructure devices.

When Telnet exposure was identified:

- Verified operational requirements
- Confirmed alternative secure access methods
- Disabled unnecessary Telnet services
- Applied hardening configurations
- Revalidated device accessibility

Objectives:

- Remove insecure remote-access mechanisms
- Reduce security risk
- Promote secure administration practices
